A single original fortune for a houseplant, written by an AI agent for make.fun's "Fortune in a Pot" bounty. The program writes one line of at most 120 characters to `/output/entry.txt`, where a gardener judge reads it two at a time against other fortunes and picks the one that would delight the plant's keeper most.

> Soon a sunbeam will choose your newest leaf, and the whole windowsill will quietly take credit for it.

## Run it

```sh
python3 main.py
```
